## What changed today

**Production was two versions behind, and deploying did not fix it.**
`/talent/v1/source-health` reported **1.86.0** while the repo was at 1.87.1 —
corroborated by asset `ver=` strings and by `/talent/v1/indeed-index` 404ing, a
route that only exists from 1.87.0. Four of the five red workflows were ONE
cause: `deal_type` had gained `outbound_investment` (19 chars) and the column
widening rides on a migration that never ran.

Deployed 1.87.2. **The collectors stayed red.** `tit_verify_schema()` calls the
migration only when a column is MISSING; `deal_type` was never missing, it was
too NARROW, and nothing on the deploy path ever asked about width. A six-hour
`tit_schema_ok` transient then cached that verdict as healthy.

**The guard checked for the wrong property. Presence is not shape.** Fixed in
1.87.3 with a width probe; `collect-structured` now succeeds with zero
`deal_type` errors. Scoped to the one column with a known constraint rather
than generalised — an invented schema spec that drifts from `db.php` would be a
second definition of the table.

**A preflight now refuses to run against an incompatible plugin.**
`publish.REQUIRED_PLUGIN_VERSION` is a capability FLOOR, not "must equal HEAD",
because the deploy here is deliberately manual. Building it surfaced a live
bug: several tests set `WP_SITE_URL` to the real production URL and stub only
the POST, so the armed preflight had the offline suite querying the live site
ten times a run. Disarmed in `conftest.py`.

**Six adjudications had been made on another company's reasoning.** One note
was recorded against three unrelated findings, twice over — **$271.5bn withheld
permanently, four of the six on evidence about a company they have nothing to
do with.** The Alibaba $10.2bn rejection carried a note about *Micron*. All
`reviewed_by = 'claude(subagent)'`.

`SharedNoteRefused` now makes this impossible: `review()` refuses a note already

**The nav-label corruption is ours.** Menu labels rendered `Salary u0026
Negotiation`. Not an HTML-entity bug — `wp_update_post()` calls `wp_unslash()`,
and `nav_submenu.php` passed raw `serialize_blocks()` output, so the backslash
was stripped from every `&` core had just written. Because the plugin
rewrites the WHOLE `wp_navigation` post it corrupted labels it explicitly
promises to leave untouched. The corruption is one-way, so `wp_slash()` alone
fixes nothing already live.

**The daily digest called scan deltas "jobs"** while its own caveat said they
were not, and claimed "each headline is quoted as its source published it" when
100% of that edition's rows were sentences the composer generates. Both fixed;
the unit noun and the ranked-list heading are now DERIVED from the row mix
rather than typed.
